Политика конфиденциальности приложения «Кубик — викторина»

Действует с 12 ноября 2026 г.

«Кубик — викторина» (далее — приложение) — бесплатная игра-викторина для Android и браузера. Эта страница объясняет, какие данные приложение использует. Коротко: приложение не собирает персональные данные и никому их не передаёт.

1. Какие данные не собираются

  • Приложение не просит регистрироваться, не спрашивает имя, телефон, e-mail.
  • Нет рекламы, нет аналитики, нет счётчиков посещений и сторонних SDK.
  • Приложение не получает доступ к контактам, фотографиям, камере, микрофону и местоположению.

2. Что хранится на устройстве

Прогресс игры (очки, звёзды, рекорды, значки, выбранный вид кубика, настройки) и вопросы, которые пользователь сам добавил в раздел «Мои вопросы», хранятся только в памяти приложения на самом устройстве. Разработчик к ним доступа не имеет. Данные удаляются вместе с приложением или при очистке его данных в настройках Android.

3. Подключение к интернету

Приложение использует интернет только чтобы скачать обновлённый список вопросов — файл с сайта marjanmik.github.io/kubik3 (хостинг GitHub Pages). При этом никакие данные пользователя не отправляются. Как любой веб-сервер, GitHub может технически фиксировать IP-адрес запроса; это регулируется политикой конфиденциальности GitHub. Без интернета игра работает полностью.

4. Кнопка «Поделиться»

Когда пользователь сам нажимает «Поделиться», приложение открывает стандартное окно Android, и пользователь выбирает, куда отправить текст, картинку с результатом или файл «Моих вопросов». Приложение ничего не отправляет само и не видит, куда и кому ушло сообщение.

5. Разрешения Android

  • Интернет — для загрузки новых вопросов (см. п. 3).
  • Вибрация — короткий отклик на ответы и повороты кубика.

6. Дети

Приложение подходит для детей и взрослых. Поскольку оно не собирает персональные данные, никакие данные детей не собираются.

7. Изменения и контакты

Если политика изменится, новая редакция будет опубликована на этой странице с новой датой. Вопросы по работе приложения и этой политике можно задать разработчику через раздел «Связаться с разработчиком» на странице приложения в RuStore.
