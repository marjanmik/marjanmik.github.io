Кубик: добавление вопросов

Вопросы добавляются в общую базу игры. Форма собирает новый файл ru.json, его нужно загрузить на GitHub в папку игры вместо старого.

Сколько вопросов в темах

Новый вопрос

Загрузить много вопросов из файла

Файл .txt в том же виде, что «Мои вопросы» в игре: вопрос, строка + верный ответ, три строки - неверные, = пояснение, уровень: 2. Вопросы разделяются пустой строкой. Все вопросы файла пойдут в выбранную выше тему. Уровень берётся из файла, а где его нет — выбранный выше.

Новые вопросы: 0

Список хранится в этом браузере, пока ты не загрузишь новый ru.json на GitHub. Потом форма сама увидит их на сайте и очистит список.

Как загрузить на GitHub

  1. Нажми «Скачать новый ru.json».
  2. Открой на GitHub свой репозиторий, папку kubik3.
  3. «Add file» → «Upload files», перетащи или выбери скачанный ru.json. Имя должно быть ровно ru.json, без «(1)» в конце.
  4. Внизу «Commit changes».
  5. Через 1–2 минуты в игре: меню → «Обновить вопросы».

Если добавил вопросы, но ещё не загрузил файл, а потом добавляешь новые — ничего страшного: список копится, следующий скачанный ru.json будет содержать все.
